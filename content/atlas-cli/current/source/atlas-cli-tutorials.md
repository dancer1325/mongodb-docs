# Manage Atlas from the Atlas CLI

Use the following tutorials to learn how to manage Atlas using the Atlas CLI. To learn the Atlas CLI basics, see install-atlas-cli and connect-atlas-cli. You can also go straight to the Atlas CLI Commands.

| Tutorial | Objective |
| --- | --- |
| atlas-cli-onboarding | Use the `atlas setup` command to onboard with Atlas, including creating your account and cluster. You can also use this tutorial to create your first cluster even if you already have an Atlas account. |
| atlas-cli-quick-start | Use the `atlas quickstart` command to create your first cluster. This tutorial requires an Atlas account and an existing organization. |
| atlas-cli-local-cloud | Find tutorials for the `atlas deployments` command, which lets you create and manage local and cloud Atlas deployments. |
| atlas-cli-ephemeral-cluster | Create an ephemeral project and cluster to test automations. |
| atlas-cli-docker | Run Atlas CLI commands with Docker. |
