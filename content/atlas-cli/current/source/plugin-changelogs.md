# Atlas CLI Plugin Changelog

## Atlas Kubernetes Operator CLI Plugin
### Atlas Kubernetes Operator CLI Plugin 1.2.1

- Adds support for Atlas Kubernetes Operator 2.11.

This release of the Atlas Kubernetes Operator CLI Plugin is compatible with the following Atlas Kubernetes Operator releases:

- 2.11.0
- 2.10.0
- 2.9.x

### Atlas Kubernetes Operator CLI Plugin 1.2.0

- Upgrades plugin with to support upstream changes in v1.47.0 of the Atlas CLI.

This release of the Atlas Kubernetes Operator CLI Plugin is compatible with the following Atlas Kubernetes Operator releases:

- 2.10.0
- 2.9.x
- 2.8.x

### Atlas Kubernetes Operator CLI Plugin 1.1.6

- Adds support for Atlas Kubernetes Operator 2.10.

This release of the Atlas Kubernetes Operator CLI Plugin is compatible with the following Atlas Kubernetes Operator releases:

- 2.10.0
- 2.9.x
- 2.8.x

### Atlas Kubernetes Operator CLI Plugin 1.1.1

- Updates the atlas-kubernetes-config-apply command to support the same features as the atlas-kubernetes-config-generate command. atlas-kubernetes-config-apply now supports the following flags, which were introduced to atlas-kubernetes-config-generate in previous releases:

   - `--dataFederationName`
   - `--independentResources`

This release of the Atlas Kubernetes Operator CLI Plugin is compatible with the following Atlas Kubernetes Operator releases:

- 2.8.0
- 2.7.x
- 2.6.x
