# Check Compatibility

The Atlas CLI supports the following operating systems:

| Operating System | Operating System Version | Architecture |
| --- | --- | --- |
| Amazon Linux | 2023 | `x86-64`, `ARM` |
| Debian | 11, 12 | `x86-64`, `ARM` |
| MacOS | 12.0 and later | `x86-64`, `ARM` |
| Microsoft Windows | 10, 11 | `x86-64` |
| Microsoft Windows Server | 2016, 2019 | `x86-64` |
| Red Hat Enterprise Linux / CentOS | 8, 9 | `x86-64`, `ARM` |
| SUSE Linux Enterprise Server | 12, 15 | `x86-64`, `ARM` |
| Ubuntu | 20.04, 22.04, 24.04 | `x86-64`, `ARM` |

## MongoDB Service Versions

The Atlas CLI supports the following versions of Atlas and MongoDB server.

| MongoDB Service | MongoDB Service Version |
| --- | --- |
| Atlas | Current |
| MongoDB server | Any [released and stable version](https://www.mongodb.com/support-policy/lifecycles) that has not reached its End of Life date. The Atlas CLI doesn't support rapid release MongoDB versions. |
