# Atlas CLI Changelog

## Atlas CLI 1.50.1

Released 20 November 2025

- Updates package dependencies.
- Fixes minor bugs.

## Atlas CLI 1.50.0

Released 23 October 2025

- Fixes an issue where the `logout` command didn't delete all of the profile configuration.

## Atlas CLI 1.49.0

Released 9 October 2025

- The `api` subcommand is now GA; note that some command names have been updated. [Read more about the api subcommand](https://www.mongodb.com/company/blog/product-release-announcements/mongodb-atlas-cli-full-api-coverage-faster-updates).
- Updates `api` commands structure to the finalized structure.
- Removes `dataLakePipelines` commands and subcommands that were previously deprecated.

## Atlas CLI 1.48.0

Released 26 September 2025

- Updates the Atlas Go SDK to the latest version.
- Adds the Atlas CLI to MongoDB 8.2 repositories.
- Adds support for `atlas deployment setup` to MongoDB 8.2.

## Atlas CLI 1.47.0

Released 11 September 2025

- Adds support for service accounts as an authentication method.
- Enables login and logout with service account profiles.
- Deprecates `atlas config init`.
- Makes `atlas config init` an alias of `atlas auth login`.
- Updates the `atlas setup` and `atlas deployment setup` commands to only provide login instead of registration if a user is not already logged in.
- Introduces new flow to `atlas auth login` to provide option to set up API key profile.
- Changes browser behavior so it does not automatically open when logging in with a user account.
- Adds a tutorial on how to authenticate an AtlasCLI profile using service accounts.
- Adds a plugin version verification for `atlas-cli-plugin-kubernetes` to ensure that a version of the plugin that is compatible with secure credential storage is used.
