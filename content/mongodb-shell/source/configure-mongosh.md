# Configure mongosh

mongosh-editor-mode  
Learn to use external or built-in editors in `mongosh` for multiline command
editing, including setting up and using editors like `vi`, `nano`, or Visual Studio.

mongosh-shell-settings  
Configure `mongosh` settings to customize shell behaviors, including logging, telemetry,
and history management, using the config API or a global configuration file.

customize-the-mongosh-prompt  
Customize the `mongosh` prompt to display dynamic session information, such as line
numbers, database and hostname, or system uptime and document count.

telemetry  
Configure telemetry options in `mongosh` to manage anonymous usage
data collection, with options to enable or disable it at any time.
