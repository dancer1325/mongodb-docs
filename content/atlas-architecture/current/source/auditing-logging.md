# Guidance for Atlas Auditing and Logging

.. meta: :description: Learn about auditing and logging in MongoDB Atlas. :keywords: logging, audit, auditing, monitoring, compliance, security, database auditing, MongoDB Atlas logging

To monitor and log Atlas platform activities, use auditing and logs.

- MongoDB Atlas Database Auditing is available on `M10+` clusters. As an Atlas administrator, you can create and enable custom JSON audit filters in MongoDB to precisely control what gets audited across your system and track system activity for deployments with multiple users. This approach lets you specify exactly which actions, database users, and Atlas roles should be monitored, giving you more granular control over your auditing process compared with the standard filter builder in the Atlas UI.
- MongoDB Atlas Logging provides a comprehensive view of platform activities, including user actions and system events. You can use the Atlas UI to view logs, or you can export logs to external systems for further analysis. Atlas logs include detailed information about database operations, user activities, and system events, enabling you to monitor performance, troubleshoot issues, and ensure compliance with security and operational policies.
