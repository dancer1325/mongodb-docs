# Cost Optimization in the Atlas Well-Architected Framework

The Cost Optimization pillar of the Atlas [Well-Architected Framework](https://www.mongodb.com/resources/products/capabilities/well-architected-framework) includes features that help you control database costs in MongoDB Atlas. Use the following Atlas Architecture Center resources to learn about cost optimization in Atlas:

- [Cost-Saving Configurations](https://mongodb.com/docs/atlas/architecture/cost-saving-config/) — Get recommendations to save costs, such as enabling auto-scaling on your cluster tier so that Atlas automatically adjusts resources based on usage and prevents over-provisioning.
- [Billing Data](https://mongodb.com/docs/atlas/architecture/billing-data/) — Leverage tags and access billing data programmatically to track your Atlas spending in your FinOps tool by environment, team, and more. Use billing dashboards to monitor usage.
