# Performance in the Atlas Well-Architected Framework

The Performance pillar of the Atlas [Well-Architected Framework](https://www.mongodb.com/resources/products/capabilities/well-architected-framework) includes features, such as automated scaling and tiered cluster storage, that allow your data operations to achieve low latency and high throughput, and scale your deployments to meet increasing demand. Use the following Atlas Architecture Center resource to learn about performance in Atlas:

- [Scalability](https://mongodb.com/docs/atlas/architecture/scalability/) — Use auto-scaling to dynamically allocate resources based on growing workload demands. For horizontal and vertical scaling, use Atlas deployment templates.
- [Latency Reduction](https://mongodb.com/docs/atlas/architecture/latency-strategies/) — Create cluster configurations that optimize read and write performance to reduce latency in your Atlas deployment.
